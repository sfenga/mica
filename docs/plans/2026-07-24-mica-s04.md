#### B. IssueStore 加 data_dir(s01 IssueStore 的扩展)
- `__init__(self, data_dir=None)`:加 `_path=None`;若 data_dir:`os.makedirs` + `_path=join(data_dir,"issues.jsonl")` + `_load()`。
- `_load`:逐行读 → `_issues[id]=_issue_from_dict(rec)`(last-wins)。
- `_persist(issue)`:若 `_path`:append `json.dumps(_issue_to_dict(issue))+"\n"`。
- 每个 mutation 后调 `_persist(issue)`。

#### C. TaskStore 加 data_dir(s02 TaskStore 的扩展)
- 同 IssueStore 模式:`__init__(data_dir=None)`,`_path=join(data_dir,"tasks.jsonl")`,`_load`(last-wins),`_persist(task)`,每个 mutation 后 `_persist`。
- `_load` 末尾调 `recover_orphans()`。

#### D. orphan 恢复(TaskStore.recover_orphans)
```python
def recover_orphans(self) -> int:
    n = 0
    for task in list(self._tasks.values()):
        if task.status in (TaskStatus.RUNNING, TaskStatus.DISPATCHED):
            task.status = TaskStatus.FAILED
            task.error = "interrupted by restart"
            task.completed_at = now_iso()
            self._persist(task)
            n += 1
    return n
```

#### E. SessionStore(同旧 s04,但 key=task_id)
```python
class SessionStore:
    def __init__(self, data_dir): self._dir = join(data_dir, "sessions"); makedirs
    def _path(self, task_id): join(self._dir, f"{task_id}.jsonl")
    def append(self, task_id, event): ev=dict(event); ev.setdefault("ts",now_iso()); append
    def load(self, task_id): 逐行读
    def summarize_if_needed(self, task_id, threshold=100, keep=20): 截断式,留近 keep + 1 summary
    def _rewrite(self, task_id, events): tmp + os.replace
```
(同旧 s04 的 SessionStore 实现,只是 key 从 issue_id 换成 task_id。keep<=0 guard + _rewrite try/finally tmp cleanup 保留。)

#### F. Daemon 加 session_store + _record + 落盘
- `__init__(..., session_store=None)`:加 `self.session_store`。
- `_record(self, task_id, event)`:若 session_store:append。
- `execute(task)`:on_event 里调 _record;claim 时记 claim;终态记 result;执行后 summarize_if_needed。
