```python
import shutil

class PathDetector:
    """探测 PATH 上可用的 agent CLI。"""
    KNOWN_CLIS = ["claude", "codex", "copilot", "opencode", "cursor-agent"]

    @staticmethod
    def detect() -> list[str]:
        """返回 PATH 上找到的 CLI 名列表。"""
        return [cli for cli in PathDetector.KNOWN_CLIS if shutil.which(cli)]

    @staticmethod
    def is_available(cli: str) -> bool:
        return shutil.which(cli) is not None
```

#### C'. MultiCliRunner 作为 runner 工厂
```python
class MultiCliRunner:
    """按 cli 名分派到对应 runner;缺失 CLI 报错。"""
    def __init__(self):
        self._runners: dict[str, AgentRunner] = {}

    def register(self, cli: str, runner):
        self._runners[cli] = runner

    def select(self, cli: str):
        """返回 cli 对应的 runner;缺失 CLI 报 KeyError。"""
        if cli not in self._runners:
            raise KeyError(f"CLI runner not registered: {cli}")
        return self._runners[cli]

    def available_clis(self) -> list[str]:
        return list(self._runners.keys())
```

这太复杂了。让我重新设计 s10 的核心:

**s10 的真正新概念是两个:**
1. PathDetector(探测 PATH 上的 CLI)
2. Daemon 1:N(claim 按 runtime_id 而非 agent_id)

MultiCliRunner 实际上在 mica 里只用 claude——不需要真正的"多 runner 分派"。简化为:PathDetector 探测可用 CLI,Daemon 1:N 认领多个 agent 的 task。

**修正后的精简设计:**

#### A. PathDetector(不变)
#### B. Runtime(不变)
#### C. Daemon 1:N 改造
Daemon 改为持 `runtime_id`,claim_next 过滤改为:
- s02 模式(1:1):`assignee_id == self.agent.id`
- s10 模式(1:N):所有 `assignee_type == "agent"` 的 queued task(因为本 daemon 托管这个 runtime 上的所有 agent)

简化:s10 的 daemon `claim_next` 不过滤 agent_id——认领本 runtime 上**所有** agent 的 queued task。runtime_id 用于标识 daemon,不在 task 上过滤(task 没有 runtime_id 字段)。

```python
class Daemon:
    def __init__(self, ..., runtime_id="local", ...):
        ...
        self.runtime_id = runtime_id

    def claim_next(self) -> Task | None:
        # s10:认领所有 assignee_type=="agent" && status==queued 的 task
        # (本 daemon 托管本 runtime 上所有 agent)
        candidates = [
            t for t in self.task_store.list()
            if t.assignee_type == "agent"
            and t.status == TaskStatus.QUEUED
        ]
        for task in candidates:
            if self.task_store.claim(task.id):
                return task
        return None
```

这样 s10 的 daemon 能认领多个不同 agent 的 task(1:N)。s02 的 1:1 测试仍通过(s02 用自己的模块)。
